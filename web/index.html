rd-core → WebAssembly · 一局 Slay the Spire 式的游戏

这一页是什么（点开） 一个静态页面 + 一个 .wasm，全局没有 CDN、没有 worker、没有 SharedArrayBuffer。 状态全部来自 rd_env_observe_buf() 那 122 个 i32；每次点击 = 一次 rd_env_step。
这一局是**从内容镜像建的**：content.sts.rdcf（11,140 B，嵌在模块里；用完整镜像而不是 9,580 B 的 core 镜像，因为卡面的标题与描述就住在 core 版被剥掉的那两格里）→ build_fight_from_content：牌组是内容里的 Characters[0].Start.Deck， 敌人是内容里的遭遇 enc_small_slimes（acid_slime_m + spike_slime_s）， 敌人意图用 intent::select_action 现算 + 从 EACT 程序里读伤害。
一次「结束回合」= 英雄回合结束 → **每个**敌人各自走一个回合（Step::EndOneTurn）→ 回到英雄。
