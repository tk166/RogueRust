{{C|Malaise}} is an X {{Icon|GE}}-cost {{QueryLink|Cards|color:Green|Silent}} {{QueryLink|Cards|rarity:Rare|Rare}} {{QueryLink|Cards|type:Skill|Skill}} Card. It gives '''negative''' X (X+1 if upgraded) {{BD|Strength}} and applies X (X+1 if upgraded) {{BD|Weak}} to the target. {{C|Malaise}} will then {{KW|Exhaust}} itself.

When playing an X {{Icon|GE}}-cost card, all {{Icon|GE}} '''Energy''' that you currently have will be consumed. The {{Icon|GE}} '''Energy''' consumed this way will be used as the value for X.

== Interactions ==
=== Synergies ===
* {{R|Paper Krane}} increases the effectiveness of {{BD|Weak}}.
* {{R|Chemical X}} makes {{C|Malaise}} apply 2 more times, regardless of the amount of {{Icon|GE}} '''Energy''' used to play it.
* If played using {{P|Distilled Chaos}}, {{C|Havoc}}, or {{C|Omniscience}}, it will play for the full current {{Icon|GE}} '''Energy''' without actually using any.
* Can be used with 0 {{Icon|GE}} '''Energy''' to advance {{R|Ink Bottle}} or {{R|Letter Opener}}.

=== Neutral ===
* If {{C|Malaise}} is duplicated with an effect such as a {{P|Duplication Potion}} or {{C|Burst}}, the value of X will also be used for the copy.
* Being an X-cost, {{C|Malaise}} can be targeted by {{C|Recycle}} to double the current {{Icon|GE}} '''Energy'''.
* It will not count as a 0-cost card for {{C|Scrape}} or {{C|All for One}}.
