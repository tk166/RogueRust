{{C|Conjure Blade}} is an X {{Icon|PE}}-cost {{QueryLink|Cards|color:Purple|Watcher}} {{QueryLink|Cards|rarity:Rare|Rare}} {{QueryLink|Cards|type:Skill|Skill}} Card. It shuffles an {{C|Expunger}} into your draw pile, which deals 9 (15 if upgraded) damage X (X+1 if {{C|Conjure Blade}} was upgraded) times. This means it is possible to generate an {{C|Expunger}} that deals damage 0 times. {{C|Conjure Blade}} will then {{KW|Exhaust}} itself.

When playing an X {{Icon|PE}}-cost card, all {{Icon|PE}} '''Energy''' that you currently have will be consumed. The {{Icon|PE}} '''Energy''' consumed this way will be used as the value for X.

== Interactions ==
=== Synergies ===
* If you have played {{C|Master Reality}} before playing this card, it will shuffle an upgraded {{C|Expunger}} into your draw pile instead.
* {{R|Chemical X}} makes the X of the {{C|Expunger}} generated by {{C|Conjure Blade}} increase by 2, regardless of the amount of {{Icon|PE}} '''Energy''' used to play {{C|Conjure Blade}}.
* If played using {{P|Distilled Chaos}}, {{C|Havoc}}, or {{C|Omniscience}}, it will play for the full current {{Icon|PE}} '''Energy''' without actually using any.

=== Neutral ===
* If {{C|Conjure Blade}} is duplicated with an effect such as a {{P|Duplication Potion}} or {{C|Burst}}, the value of X will also be used for the copy.
* Being an X-cost, {{C|Conjure Blade}} can be targeted by {{C|Recycle}} to double the current {{Icon|PE}} '''Energy'''.
* It will not count as a 0-cost card for {{C|Scrape}} or {{C|All for One}}.

{{C|Expunger}} is a 1 {{Icon|CE}}-cost {{QueryLink|Cards|color:Colorless|Colorless}} {{QueryLink|Cards|rarity:Special|Special}} {{QueryLink|Cards|type:Attack|Attack}} Card. It deals 9 (15 if upgraded) damage X times. 

Uniquely, X is not decided by the {{Icon|CE}} '''Energy''' you have when this card is played, but by the {{Icon|CE}} '''Energy''' you had when the {{C|Conjure Blade}} that created this was played. This means that X is consistent per copy of {{C|Expunger}} from the moment it is created. If X is 0, this card does nothing.
