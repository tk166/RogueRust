'''Jaw Worm''' is a normal [[Monsters|Enemy]] that can show up in Act 1, and has a hard variant that can show up in Act 3.

Always starts with {{Int|Jaw Worm|Chomp}}. If it is found in Act 3, it starts with the effects of {{Int|Jaw Worm|Bellow}}, and for its first action it has a 45% chance of starting with {{Int|Jaw Worm|Bellow}}, a 30% chance of {{Int|Jaw Worm|Thrash}} and a 25% chance of using {{Int|Jaw Worm|Chomp}}
* After using {{Int|Jaw Worm|Chomp}}, it has a 59% chance of using {{Int|Jaw Worm|Bellow}} and a 41% of {{Int|Jaw Worm|Thrash}}
* After using {{Int|Jaw Worm|Bellow}}, it has a 56% chance of using {{Int|Jaw Worm|Thrash}} and a 44% of using {{Int|Jaw Worm|Chomp}}
* After using {{Int|Jaw Worm|Thrash}}, it has a 45% chance of using {{Int|Jaw Worm|Bellow}}, a 30% chance of using {{Int|Jaw Worm|Thrash}} and a 25% chance of using {{Int|Jaw Worm|Chomp}}. Unless {{Int|Jaw Worm|Thrash}} has been used 2 turns in a row, then it has a 64% chance of using {{Int|Jaw Worm|Bellow}}, and a 36% of using {{Int|Jaw Worm|Chomp}}
