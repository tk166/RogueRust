== Spiker ==
{{Enemy Infobox
| Name   = Spiker
| Link   = Shapes#Spiker
| Image  = Spiker.png
| HP     = 42-56
| AscHP  = 44-60
| Powers = {{BD|Thorns}} 3 ({{Asc|2|4}} {{!}} {{Asc|17|7}})
| Debut  = Act 3
| Type   = Normal
}}
{{Power Infobox|Thorns}}
Spikers focus on building up {{BD|Thorns}} to make them more dangerous to kill as the battle progresses.

=== Pattern ===
{{Intents Table/start|Spiker}}
{{Intents Table/row
| Name   = Attack
| Intent = Attack2
| Effect = Deals (7;{{Asc|2|9}}) damage.
}}
{{Intents Table/row
| Name         = Buff Thorns
| Intent       = Buff
| Effect       = Gains 2 {{BD|Thorns}}.
| GivesToEnemy = Thorns
}}
{{Intents Table/end}}
On every turn, it has a 50/50 chance of using either {{Int|Spiker|Attack}} or {{Int|Spiker|Buff Thorns}}.

Cannot use {{Int|Spiker|Attack}} twice in a row. Cannot use {{Int|Spiker|Buff Thorns}} once it has been used 6 times and will instead using {{Int|Spiker|Attack}}.

{{Clear}}
